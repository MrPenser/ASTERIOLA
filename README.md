# ASTERIOLA

**Original Music — Music that stays with you.**

ASTERIOLA is an original-music project covering Russian and English vocal songs and electronic / cinematic instrumentals. Production hypotheses and quality gates are researched under the ASTERIOLA Music Engine (AME).

## Project rules

- [LYRIC-C01 — «Созвездия чувств»](docs/rules/LYRIC-C01.md): mandatory association-first lyric-writing rule (approved 2026-10-10). Applies to original lyrics and revisions; direct emotional labels are not a substitute for psychologically grounded imagery.

## Governance

GitHub contains project documentation and reproducible rules. Approved concepts are not proof of musical success or production readiness. Changes to approved rules require explicit project-owner approval; technical and commercial gates are tracked independently.
